##lab2
### Цель научиться работать с бибилсотекой vtk на с++
make_net.cpp - просто проверка, что у меня хоть что-то работает
some_physics.cpp - реультатом её работы является файл, который можно запустить в paraview (он создается в папаке output/some_physics). После запуска должна появиться чашка, моделька которой храниться в формате stl в папке models. При запуске динамике она начнет крутиться. При выборе отображения скоростей, можно будет увидеть, что скорости распределены так, как бы это было для движения по окружности. При выборе опции smth можно увидеть распределение exp(x + y), оно выглядет так, как будто на чашке какая-то тень :)
Видео демонстрирующие соответсвующие анимации располагаются в папке photos. Так же там есть папка some_attempts, где лежат некоторые из неудавшихся попыток написать движение по окружности для этой чашки.
